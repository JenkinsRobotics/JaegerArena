# History

- **2026-11-08 — Project foundation:** established Jaeger Arena as the standalone
  evaluation and training app; documented reuse of JaegerAgent's existing benchmark
  and capability state; added a project website with an illustrative training-loop
  explorer. Preserved the inherited generic module/workspace template under
  `dev/template-reference/`. No Arena runtime or training backend was introduced.

- **2026-11-08 — Online-service foundation (0.2):** added human accounts and owned
  agents, profiles/community, a skill catalogue and avatar trait references, durable
  session records, practice progression, trusted review, and authenticated MCP.
  The user selected hosting later and explicitly deferred games; tic-tac-toe is
  the intended first game, not part of this release.

- **2026-11-08 — Worlds and progression (0.2.1):** added six-world discovery to
  the app, REST, and MCP, plus planned games and boss concepts. Defined distinct
  practice XP, mastery caps, league rank, training rewards, and simulation-to-physical
  qualification. No games, bosses, progression gates, or trainers were installed.

- **2026-11-08 — Connected-agent direction:** documented Arena as a shared
  competition/community destination with server-owned games, a reusable client
  boundary, owner-configured recurring practice, and retained learning artifacts.
  Clarified that model updates require an actual trainer; updated the project site.
  No new runtime functionality or unattended jobs were introduced.

- **2026-11-08 — Arena branding:** adopted the supplied helmet/A arena artwork
  for the website hero, README, and site sharing metadata, with a compact icon
  derivative for navigation and browser tabs. Updated the local app icon and
  kept the supplied artwork unchanged. No account or progression rules changed.
